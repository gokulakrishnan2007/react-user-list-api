# React User List API

## 📌 About the Project
This project is built using React.js to fetch and display user details
from the JSONPlaceholder API.

## 🚀 Features
- Fetch user data from an API
- Display user details in reusable cards
- Show email and phone number
- Display city and company details
- Loading state while fetching data
- React Hooks: useState and useEffect

## 🛠️ Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- JSONPlaceholder API
- Vite

## ⚙️ Installation and Setup

1. Clone the repository:
   git clone https://github.com/gokulakrishnan2007/react-user-list-api.git

2. Navigate to the project folder:
   cd react-user-list-api

3. Install dependencies:
   npm install

4. Start the development server:
   npm run dev

## 🌐 API Used
https://jsonplaceholder.typicode.com/users
